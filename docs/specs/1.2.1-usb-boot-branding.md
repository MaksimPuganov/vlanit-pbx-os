# Спецификация: 1.2.1 — загрузка с USB-флешки, брендинг, гигиена репозитория

Статус: **реализовано** (1.2.1, тесты Т1–Т9 PASS).

## 1. Загрузка с USB-носителя на реальном железе

Фидбек: в QEMU с виртуальным CD оба дефекта маскировались; на железе с
флешки (dd) образ не стартовал.

Решения:

1. **GRUB EFI без fat-модуля не читал свой конфиг** с ESP-раздела флешки
   (grub.cfg лежит на FAT). В `grub-mkimage` добавлены `fat`, `png`,
   `gfxterm`, `gfxterm_background`, `bitmap`, `bitmap_scale`.
2. **`vlanit-init` не видел флешку**: добавлены модули `usbcore`,
   `usb-storage`, `uas`, `xhci-hcd`, `xhci-pci`; поиск носителя расширен
   на `/dev/sd*`, `/dev/vd*`, `/dev/nvme*n*`; сканирование с повторами
   (8 × 2 с) — USB-накопители «прогреваются» (media ready) после появления
   узла устройства.
3. Регрессионный тест: все сценарии по умолчанию грузят ISO через
   `usb-storage` (`MEDIA=usb`), т.е. воспроизводят путь железа
   (ESP → GRUB → initramfs → установка с /dev/sdX).

## 2. Фирменный брендинг (vlanit.com)

Палитра с сайта: фон `#09090b`, светлый `#F5F4F0`, акцент-золото `#D4AA6A`
(глубокий `#B8965A`), серый `#8A8680`. Логотип — официальный SVG
(`branding/vlanit-logo-on-dark.svg`).

- **GRUB**: фон 1920×1080 (градиент фирменного тёмного + золотые полосы),
  выделение пункта жёлтое, шрифт `unicode.pf2` (DejaVu Sans Mono,
  диапазон U+20–U+2FFF — кириллица, стрелки, псевдографика; без него
  встроенный шрифт GRUB рисует рамку меню «d»). Реализация — `background_image`
  + `terminal_output gfxterm` (theme.txt отказаны: desktop-image в EFI
  грузится нестабильно).
- **Консоль**: `/etc/issue` — баннер VLANit золотым ANSI (truecolor),
  MOTD, `ANSI_COLOR` в os-release.
- Ассеты (PNG, PF2) **генерируются при сборке** в build-контейнере
  (`python3-cairosvg`, `python3-pil`, `fonts-dejavu-core`, `grub-mkfont`) —
  в git только SVG и генераторы.

## 3. Гигиена репозитория

- В git **нет бинарников**: история переписана (`git-filter-repo`), pack ~117 КБ.
- Пакеты сборочной машины — манифест `tools/fetch-tools.sh` + `tools/README.md`;
  `tools/debs`, `tools/root` — в `.gitignore`.
- Версия дистрибутива больше не «1.2» в имени файла: `VLANit-PBX-1.2.1-amd64.iso`.
