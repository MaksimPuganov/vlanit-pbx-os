# Спецификация: тестирование 1.2 (Т8, Т9)

Статус: принято. Приоритет: высокий (блокирует релиз 1.2).

## Т8 — Обновление и откат (OTA)

Окружение: установленная система (автоустановка с `VLANIT_TEST=1`),
подключённый «USB-носитель» = второй virtio-диск с записанным
подписанным пакетом обновления (готовится в setup-скрипте теста:
сборка пакета с заведомо новым тегом образа).

Сценарий:
1. Тест формирует пакет: новый образ АТС (перетег существующего,
   версия `2026.6.99-test1`), manifest, подпись тестовым GPG-ключом
   (ключ зашивается в ISO подконтрольным образом — вариант: тестовый
   ключ в каталоге tests/, включение через kernel_args `VLANIT_TEST_GPG=1`).
2. `vlanit-update` без аргумента находит пакет на /dev/vdb.
3. Негатив: пакет с битым байтом → отказ, система не изменена.
4. Позитив: подтверждение `YES` → снапшот `pre-update` → образ обновлён →
   health-check PASS. Проверки агента: `mikopbx-webui`, новая версия
   образа (`podman images`), снапшот `pre-update` существует.
5. Откат: `vlanit-rollback` → reboot → проверки: версия образа прежняя,
   конфигурация `/cf` из снапшота, MikoPBX healthy.

Критерий: все проверки PASS; время сценария ≤ 15 минут в QEMU.

## Т9 — Бэкап на USB

Окружение: как Т8, плюс маркер-файл в `/storage` перед бэкапом.

Сценарий:
1. `vlanit-backup` → архив на /dev/vdb; проверки: файл создан, manifest
   валиден, контейнер вернулся в healthy.
2. Модификация данных в `/cf` (через API или файл-маркер), затем
   ручное восстановление по инструкции troubleshooting.md (выполняет
   тест-агент по шагам).
3. Проверка: данные соответствуют состоянию на момент бэкапа.

Критерий: восстановленная конфигурация совпадает с бэкапом; MikoPBX healthy.

## Расширение агента

Новые проверки (только при соответствующих условиях):
- `security-unattended-upgrades` — `unattended-upgrades --dry-run` rc=0;
- `security-root-ssh-denied` — `sshd -T | grep permitrootlogin` → `no`;
- `security-fail2ban` — служба активна, джейл sshd существует;
- Т8/Т9 — по маркерам в kernel cmdline (`VLANIT_TEST=ota|backup`),
  выполняются тест-скриптами с хоста, не в базовом агенте.
