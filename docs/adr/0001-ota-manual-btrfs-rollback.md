# OTA: ручные обновления с откатом из Btrfs-снапшота

Контекст: решение архитектуры обновлений для 1.2. Решили: обновления
(АТС + системные пакеты) применяются только вручную через команду
`vlanit-update`, доставка — двумя каналами (подписанный пакет на USB или
онлайн при наличии сети), пакеты подписаны GPG-ключом релиза. Перед
применением создаётся read-only Btrfs-снапшот; откат — восстановлением
subvolume из снапшота (`vlanit-rollback`, с перезагрузкой).

Почему: АТС — телефония, автоматическое применение обновлений может
прервать звонки; снапшоты Btrfs уже встроены в дисковую схему и дают
надёжный откат без отдельного механизма бэкапа. Ручное применение
снимает класс проблем «обновилось ночью и сломалось», а GPG-подпись
защищает от подмены пакета на USB-носителе, который физически
контролируется не нами.
