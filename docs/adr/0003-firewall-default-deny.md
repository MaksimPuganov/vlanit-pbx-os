# Firewall по умолчанию: управляемая политика default-deny

Контекст: решение о сетевой политике устройства (пункт 3 полевых тестов 1.2.2).
Решили: в Golden Image включаем nftables с `input policy drop` и явным
перечнем разрешённых портов: loopback, established/related, SSH 22,
WireGuard 51820, веб MikoPBX 80/443, SIP/RTP (udp 5060, tcp 5060/5061,
udp 10000-10800). Ограничение управляющих портов по подсетям админа —
документированная опция (`ip saddr … accept`), не дефолт.

Почему: до 1.2.4 все порты АТС и управления были открыты на всех
интерфейсах с включённым форвардингом. Альтернативы: (а) ничего не делать
и полагаться на fail2ban — реактивно, не закрывает поверхность; (б) закрыть
и порты АТС — ломает телефонию, АТС должна быть достижима для SIP-транков
и клиентов; (в) политика default-deny с явными разрешениями — закрывает
всё лишнее, сохраняет функциональность, стандарт для апплаенсов.

Отклонённые варианты: `HandlePowerKey=suspend` (соседняя задача, но по той
же логике — «спящая» АТС не принимает звонки); маскарадинг wg+ — отложен
до сценария road-warrior.
