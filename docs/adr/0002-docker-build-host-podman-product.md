# Docker на сборочной машине при Podman в продукте

Контекст: выбор рантайма для build-контейнера сборки ISO. Решили: сборка
выполняется в привилегированном Docker-контейнере (`scripts/Dockerfile.build`),
при этом в самой VLANit PBX OS Docker отсутствует — контейнерный рантайм
продукта — rootful Podman с systemd Quadlet.

Почему: rootless Podman в ряде окружений сборочных машин заблокирован
(newuidmap возвращает EPERM при записи uid_map — проверено), rootful Podman
требует sudo; Docker оказался единственным работоспособным рантаймом без
root на хосте. Продукт при этом соответствует требованию «Podman вместо
Docker»: Docker существует только как инструмент машины, собирающей ISO,
и не попадает ни в образ, ни в установленную систему.
