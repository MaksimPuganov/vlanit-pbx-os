# VLANit PBX OS

Установочный ISO и операционная система для автоматического развёртывания
MikoPBX на физических устройствах. Единый контекст проекта.

## Language

**Устройство**:
Аппарат (x86-64 компьютер или сервер) с установленной VLANit PBX OS.
_Avoid_: сервер, ящик, железка, АТС (АТС — это MikoPBX, не устройство)

**АТС**:
Программный продукт MikoPBX, запущенный в контейнере на Устройстве.
_Avoid_: PBX-сервер, телефония (телефония — предметная область, не компонент)

**Релиз**:
Опубликованная версия дистрибутива: ISO + версия + манифест + checksums.
_Avoid_: сборка, билд (сборка — процесс, Релиз — его опубликованный результат)

**Обновление АТС**:
Замена контейнерного образа MikoPBX на новый; конфигурация в /cf сохраняется.
_Avoid_: апгрейд телефонии, обновление ISO

**Обновление системы**:
Обновление системных пакетов Debian (apt) на Устройстве.
Не путать с Обновлением АТС — разные пакеты, разный риск, разный механизм.
_Avoid_: патч ОС, апгрейд дистрибутива

**Пакет обновления**:
Подписанный GPG tar-архив с образом АТС и метаданными версий,
доставляемый на Устройство через USB или сеть.
_Avoid_: бандл, апдейт-файл

**Golden Image**:
Переносимый слепок файловой системы устанавливаемой ОС (tar.zst),
разворачиваемый установщиком на диск Устройства.
_Avoid_: образ диска, шаблон (образ диска — поблочный слепок, мы его не используем)

**Установщик**:
TUI-мастер первичной установки из Live-окружения ISO на диск Устройства.
_Avoid_: инсталлятор, мастер настройки (настройка — отдельный этап, provisioning)
